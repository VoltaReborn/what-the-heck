# What the Heck PWA

GitHub Pages-ready PWA files.

## Files

- `index.html` - the game
- `manifest.webmanifest` - PWA manifest
- `sw.js` - service worker for offline caching
- `icons/` - put your icon image files here

## Icon files to add

Required:
- `icons/icon-192.png` — 192 × 192 PNG
- `icons/icon-512.png` — 512 × 512 PNG
- `icons/apple-touch-icon.png` — 180 × 180 PNG

Recommended:
- `icons/icon-maskable-512.png` — 512 × 512 PNG, with generous padding around the artwork for Android maskable icon cropping.

The app splash screen uses `icons/icon-512.png`.
